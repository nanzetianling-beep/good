# 引き継ぎ書: POS に3つの設定を追加する

作成日: 2026-09-30
対象リポジトリ: `pokkiriofficial/nightwork-pos`(POS 本体。Vercel プロジェクト nightwork-pos)
関連: 導入アンケート https://pokkiri-night-survey.vercel.app(リポジトリ `nanzetianling-beep/good`)

このファイルだけで作業を始められるように書いています。
アンケート側の詳しい書式と全質問の一覧は、`nanzetianling-beep/good` の `docs/pos_handoff.md` にあります。

## やること(この作業の範囲)

導入アンケートに追加した3つの項目を、POS の店舗の設定に追加する。

| 設定 | 店舗の設定(管理画面) | フロア画面(iPad) |
|---|---|---|
| 個室料・VIP席料 | 追加する | 設定できるようにする |
| ボトルキープの期限 | 追加する | 設定できるようにしない |
| 会計のタイミング | 追加する | 設定できるようにする |

あわせて、運営コンソールの「導入アンケートの取り込み」(貼り付け)で、この3つを読み取れるようにする。

## 1. 個室料・VIP席料

- 意味: 個室やVIP席を使った卓だけにかかる料金。その卓の会計に1回付く
- ハウスチャージとは別。ハウスチャージは、すべての卓の会計に付く料金
- 持つもの: 有無(なし/あり)と、席ごとの料金の一覧(席の名前・料金(円))
- 例: VIPルーム 5,000円、個室A 3,000円
- 会計: その席を使った卓の会計に、決めた料金を1回だけ足す
- フロア画面: 案として、卓を開くときか会計のときに、個室・VIP席を使ったかを付け外しできる形を検討する。操作は今の卓の画面に合わせて決める

## 2. ボトルキープの期限

- 意味: キープしたボトルを、いつまで預かるか
- 選択肢: ボトルキープなし / 期限なし / 1か月 / 2か月 / 3か月 / 6か月 / 1年
- 数え方: 最後に来店した日から数える
- 例: 「3か月」なら、3か月来店がないと期限切れ
- 店舗の設定(管理画面)だけで変えられればよい。フロア画面には出さない

## 3. 会計のタイミング

- 意味: 料金セットがないお店の、お会計のしかた
- 選択肢: 帰るときにまとめて会計 / 注文ごとに支払い(キャッシュオン)
- アンケートでは、料金セットの有無が「なし」のときだけ聞いている
- 帰るときにまとめて会計: 注文を伝票に付けて、最後に払う
- 注文ごとに支払い: 1杯ごとに、その場で払う。案として、注文を入れたときにその場で会計できる形を検討する(今のPOSの会計の流れを確かめてから決める)
- フロア画面でも切り替えられるようにする

## アンケートの回答の書式(取り込み用)

店舗は回答を「文章をコピー」して LINE で送る。運営コンソールで貼り付けて取り込む。
外部から送信する経路(API・共有シークレット)は作らない(2026-09-26 の方針)。

1問ごとに、空行・「■質問名」・答え の順に並ぶ。今回の3項目は次のように届く。

```
■個室料・VIP席料の有無
あり

■個室料・VIP席料
VIPルーム/5000、個室A/3000

■ボトルキープの期限
3か月

■会計のタイミング
注文ごとに支払い(キャッシュオン)
```

- 表は、1行の中を「/」、行どうしを「、」でつなぐ。空のマスは `-`
- 「未定」は、まだ決まっていないという答え。設定は変えずに、未設定のままにする
- 条件に合わない質問は書かれない(個室料が「なし」なら表は来ない。料金セットが「あり」なら会計のタイミングは来ない)

## 気をつけること

- 貼り付け画面が落ちることがあると報告されている。取り込みを触るときは、落ちる入力を再現してから直す(`docs/pos_handoff.md` のやること一覧で最優先)
- 個人情報・給与・ログイン情報の項目は作らない
- アンケートの最後のページで「あとから管理画面・フロア画面(iPad)の設定で変更できます」と案内している。今回の3つも、表のとおり変更できるようにする

- 店舗の設定とフロア画面で、3つを設定・変更できることを画面で確かめる
- 上の書式の文章を貼り付けて、3つが店舗の設定に入ることを確かめる
