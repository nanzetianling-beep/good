## ⚠ このファイルの決まりごと

`kaiten-jitaku.html` は、**ふつうのHTMLファイルではありません。**
公開するときに外側の骨組みが自動で足される前提で書かれています。

### 1. `<!doctype>` `<html>` `<head>` `<body>` を書かない

公開時に、この4つは自動で付きます。
自分で書くと二重になって壊れます。

ファイルの先頭は `<title>` から始めてください。
`<style>` もそのまま本文中に置いて構いません。

ローカルで開くときの骨組みは `preview.mjs` が被せています。

### 2. 外部ファイルは、決まった置き場からしか読めない

公開ページには読み込み制限（CSP）がかかっています。

| 種類 | 読めるところ |
| --- | --- |
| スクリプト | cdnjs.cloudflare.com / cdn.jsdelivr.net/npm / cdn.tailwindcss.com / code.jquery.com |
| スタイルシート | fonts.googleapis.com のみ |
| フォント本体 | fonts.gstatic.com |

これ以外は、画像もCSSも通信も**すべて黙って失敗します。**

画像を足したいときは、データURI（`data:image/...`）で埋め込んでください。
CSSとJSも、外部ファイルに切り出さず、このファイルの中に書きます。

### 3. ダークモードは3状態ある

色はすべて `:root` のCSS変数で定義しています。
明るい配色を `:root` に、暗い配色を次の2か所に書いています。

```css
:root { --ink:#16233d; }                                  /* 明るいとき */
@media (prefers-color-scheme:dark){
  :root:not([data-theme="light"]){ --ink:#e8edf7; }        /* OSが暗いとき */
}
:root[data-theme="dark"]{ --ink:#e8edf7; }                 /* 明示的に暗いとき */
```

**色を直接書かず、必ず変数を使ってください。**
片方のテーマでしか定義されていない色は、もう片方で文字が消えます。

## 中身の地図

1ファイルですが、`═══` のコメントで7つに区切ってあります。

| 節 | 中身 |
| --- | --- |
| 1. 用語集 | `TERMS`。難しい言葉の説明を28語ぶん持っています |
| 2. 見本のデータ | `SAMPLE()` と `EMPTY()`。開いた直後に入っている値 |
| 3. 領収書の見本 | 実際に紙へ刷られる絵を描くコード。POS本体からの移植です |
| 4. 画面の中身 | `CHAPTERS` と `STEPS`。**編集の9割はここです** |
| 5. 状態 | 入力値の保存と読み出し（localStorage） |
| 6. 描画 | `STEPS` をHTMLに変換します |
| 7. 操作 | クリックと入力の受け取り |

### いちばん触るところ: `STEPS`

1ページが1つのオブジェクトです。
ページを足すときは、配列に1つ足すだけで、目次も進捗も自動で追従します。

```js
{ ch:0,                       // 何章目か（CHAPTERS の添え字）
  title:"お店の名前と連絡先",
  lead:"お客様に見せる名前と、連絡がつく場所を入れます。",
  why:"ここで入れた4つは、そのまま領収書に印刷されます。",
  groups:[{ t:"お店の情報", note:"", fields:[ /* 入力欄 */ ] }] }
```

### 入力欄の書きかた

```js
{ k:"store.name",        // 保存先。"casts.0.name" のような階層も書けます
  label:"お店の名前",
  req:1,                 // 必須にする。埋まるまで次へ進めません
  type:"text",           // text / num / select / time / date / toggle / choice / list
  ph:"CLUB ポッキリ",     // 薄く出る例
  half:1,                // 2列組みにする（既定は横いっぱい）
  what:"お客様に見せる、お店の正式な名前です。",  // これは何？
  eg:"CLUB ポッキリ ／ Lounge 月",              // たとえば
  use:"領収書の右下に出ます。",                  // どこで使われる？
  when:()=>S.lns.on==="yes" }                   // 条件付きで出す
```

`what` `eg` `use` の3つは、**全項目に付けるのが約束です。**
中学生でも迷わないことを目的にした画面なので、ここを省くと設計が崩れます。

### 難しい言葉の出しかた

`what` `use` `note` `hint` の文中で `【採番】` と囲むと、
押せる用語チップになります。

説明文は `TERMS` に足してください。
`TERMS` に無い言葉を囲んでも、ただの文字として出るだけです。

### くり返し入力（`type:"list"`）

席・商品・キャストのような一覧は、1件が1枚のカードになります。

```js
{ k:"tables", type:"list", req:1,
  itemName:"席",            // カードの見出しに出ます
  addLabel:"席を追加",
  nameField:"name",         // カードの背表紙に出す項目
  big:1,                    // 項目が多いとき（小見出しで区切れます）
  sub:[
    {head:"連絡先"},                                   // 小見出し
    {k:"name", label:"席の名前", type:"text", ph:"1番テーブル"},
    {k:"seats", label:"すわれる人数", type:"num", unit:"人"} ] }
```

`sub` に項目を足したら、`SAMPLE()` の同じ配列にも同じキーを足してください。
`EMPTY()` は `SAMPLE()` から自動で作られるので、こちらは触らなくて大丈夫です。
