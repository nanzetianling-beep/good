# 初期設定一覧シート セットアップスクリプト

Googleスプレッドシートに「初期設定一覧」という管理表を自動生成する
Google Apps Script です。

対象ファイル：[`初期設定セットアップ`](https://docs.google.com/spreadsheets/d/1Wx2ZtBfDhfno0FL3GSaLN4ZJo6PhFtXe29awqUumF3Q/edit)（nanzetianling@gmail.com のマイドライブ・シート名「初期設定一覧」）

ヘッダー・列ごとの配色・列幅・状態プルダウン・状態別カラー・1行目固定・
フィルター・罫線といった「大枠」だけを用意した状態で作成済みです。
2行目以降の中身は空なので、そのまま入力していけます。

見た目が想定と違う場合や、500行目まで書式を広げたい場合に下記スクリプトを実行してください。
（入力済みの内容はそのまま残ります）

---

## 導入手順

1. スプレッドシート「初期設定セットアップ」を開く
2. メニューの **拡張機能 → Apps Script** をクリック
3. エディタに出ている `function myFunction() {}` を消して、
   [`setupInitialSettingsSheet.gs`](./setupInitialSettingsSheet.gs) の中身を全部貼り付ける
4. 保存（Ctrl+S / ⌘+S）
5. 上部の関数プルダウンで **`setupInitialSettingsSheet`** を選び、**実行**
6. 初回のみ権限の承認画面が出るので、アカウントを選んで許可する
   （「このアプリは確認されていません」と出たら、
   「詳細」→「（プロジェクト名）に移動」→「許可」）
7. 数秒で「初期設定一覧」シートが出来上がります

> スクリプトを別ファイルから実行したい場合は、
> ファイル冒頭の `TARGET_SPREADSHEET_ID` に対象スプレッドシートのIDを入れてください。
> （URLの `/d/` と `/edit` の間の文字列がIDです）

## 実行すると作られるもの

| 項目 | 内容 |
| --- | --- |
| シート | 「初期設定一覧」（無ければ新規作成／あればそのまま使用） |
| 列構成 | A:No. / B:大項目 / C:小項目 / D:内容・設定 / E:理由 / F:メモ / G:状態 |
| ヘッダー | 濃紺 `#1F3557` ＋ 白文字・太字・中央揃え・行高45px |
| 大項目 | 薄紺 `#EAF0F8` ＋ 濃紺文字・太字 |
| 小項目 | 白背景・太字・濃いグレー |
| 内容・設定 | 白背景・左揃え・折り返しON |
| 理由 | 薄グレー `#F5F5F5`・折り返しON |
| メモ | 薄黄色 `#FFF8E1`・折り返しON |
| 状態 | プルダウン（完了／確認中／未対応／不要）＋状態別の色 |
| 固定 | 1行目を固定 |
| フィルター | A1:G500 に設定 |
| 罫線 | 薄グレー `#DADCE0`／ヘッダー下と大項目の切り替わりは少し太め |
| 行高 | 内容に応じて自動調整・最低40px |
| 事前書式 | 500行目まで（後から行を足しても書式とプルダウンがそのまま使える） |

## 安全設計

このスクリプトは既存データを勝手に消しません。

- `deleteSheet()` / `clear()` / `clearContents()` は一切使っていません
- 同名シートがある場合は、削除せずそのシートをそのまま使います
- 既定ではサンプルデータを入れません（`INSERT_SAMPLE_DATA = false`）
  サンプルが必要なときだけ true にしてください。true でも
  **2行目以降が完全に空のときだけ** 入力します
- 行数・列数は足りないときに増やすだけで、減らすことはしません

そのため、**何度実行しても安全**です（書式を直したいときの再実行もOK）。

---

## カスタマイズ

色・列幅・行数などはファイル冒頭の「設定エリア」にまとまっています。

- 色を変える → `COLORS`
- 列幅を変える → `COLUMN_WIDTHS`
- 行の高さを変える → `ROW_HEIGHT`
- 事前に書式を用意する行数を変える → `MAX_ROWS`
- 状態の選択肢を増やす → `STATUS_OPTIONS` に1件追加するだけで、
  プルダウンと色付けの両方に自動反映されます
- サンプルデータを入れたい → `INSERT_SAMPLE_DATA` を true にする

---

## 入力ルール（表を使うときの決まりごと）

- **1行につき小項目は1つ**（「店舗名・営業時間・電話番号」のようにまとめない）
- **セル結合はしない**（フィルターと並び替えが使えなくなるため）
- 大項目が同じでも、各行に大項目名を毎回入力する

```
店舗基本設定 ｜ 店舗名
店舗基本設定 ｜ 営業時間
店舗基本設定 ｜ 電話番号
```
