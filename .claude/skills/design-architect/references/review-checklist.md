# 自己批判的レビュー チェックリスト (Review フェーズ)

実装完了後、必ず以下を検証し、結果と改善案をユーザーに提示する。

## A. アクセシビリティ (WCAG 2.2 AA)

- [ ] テキストのコントラスト比: 通常テキスト 4.5:1 以上 / 大きいテキスト(24px〜 or 太字19px〜) 3:1 以上
- [ ] UIコンポーネント・グラフィックのコントラスト: 3:1 以上
- [ ] フォーカスインジケータが視認可能(`:focus-visible` を消していない)
- [ ] タッチターゲット: 最低 24×24px (推奨 44×44px)
- [ ] 色だけに依存した情報伝達をしていない(アイコン・ラベル併用)
- [ ] `prefers-reduced-motion` でアニメーションを抑制している
- [ ] 見出し階層(h1→h2→h3)が飛んでいない / ランドマーク(`main`, `nav`, `footer`)がある
- [ ] 画像に適切な `alt`、装飾画像は `alt=""`
- [ ] フォームに `label` が関連付いている / エラーはテキストで伝える
- [ ] キーボードのみで全操作が完了できる

## B. セマンティクスと保守性

- [ ] `div`/`span` の乱用がない(`button`, `a`, `ul`, `table` 等を適切に使用)
- [ ] スタイル値がすべてデザイントークン経由(マジックナンバーなし)
- [ ] クラス命名が既存規約と一致している
- [ ] レスポンシブ: モバイル(375px)・タブレット(768px)・デスクトップ(1280px)で破綻しない
- [ ] ダーク/ライト両テーマで検証した(テーマ対応がスコープ内の場合)

## C. デザイン品質(芸術的感性の検証)

- [ ] 視覚階層: ユーザーの視線が意図した順に流れるか(Z型/F型)
- [ ] 余白のリズムが一貫している(スケール外の余白がない)
- [ ] 型スケールに一貫した比率がある(1.2/1.25/1.333等)
- [ ] インタラクション状態(hover/active/disabled/loading)がすべて定義されている
- [ ] 「なぜこのデザインか」を1文で説明できる

## D. 報告フォーマット

レビュー結果は以下の形式で提示する:

```
### セルフレビュー結果
✅ 合格: ...
⚠️ 要注意: ...(理由と対応)
💡 改善提案: ...(実施しなかった理由も添える)
```
