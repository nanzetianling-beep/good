# 5. バックの決め方

同席してほしい人:オーナー・店長

---

<div class="time">5章 〔目安 15分〕</div>

## バックは10パターンから選びます

| パターン | 内容 |
|---|---|
| ① 指名バック | 指名ごとに、円か指名料の%で支給 |
| ② 担当卓売上バック | 担当した卓の売上の% |
| ③ 商品バック | 特定の商品を出したキャストに支給 |
| ④ ボトル折半 | ボトル1本を、付いたキャストで分ける |
| ⑤ スライド | 月間の実績で率が上がる |
| ⑥ 時給併用 | 時給に①〜⑤を上乗せ |
| ⑦ 保証比較 | 日給保証と①〜⑥の高い方 |
| ⑧ ポイント時給 | ポイントで時給が変わる |
| ⑨ 本数ボーナス | 月の指名本数で固定ボーナス |
| ⑩ ヘルプバック | 他のルールに係数をかけてヘルプへ |

---

<div class="time">5章 〔目安 15分〕</div>
