# 自然な日本語 (Natural Japanese)

## 概要

このスキルは、AIが生成しがちな「不自然な日本語」を、人間が書いたように自然で読みやすい日本語へ書き換える（リライトする）ためのものです。翻訳調・機械翻訳調のぎこちなさ、冗長な言い回し、単調なリズムを取り除き、指定されたトーン&マナー（トンマナ）に沿った文章に仕上げます。

大前提として、**原文の意図・事実・ニュアンスは変えない**こと。自然さのために内容を勝手に足したり削ったりしない。整えるのは「言い回し・語順・語尾・リズム・表記」であって、主張ではありません。

## いつ使うか

- 生成AIやAI翻訳（DeepL / ChatGPT 等）の出力が「AIっぽい」「かたい」「翻訳っぽい」と感じるとき
- SNS投稿・ブログ記事・メルマガなど、公開前の文章を人間らしく推敲したいとき
- ブランドや個人の「らしさ（トーン&マナー）」に文体をそろえたいとき
- 既存のお手本（過去記事・投稿・ガイドライン）と同じ文体で新しい文章を書きたいとき（→ Reference Folder を使う）

逆に、**契約書・仕様書・法令のような一字一句の厳密さが最優先の文書**では、リズム優先の書き換えをしないこと。正確性を崩さない範囲にとどめます。

## AIっぽい日本語の症状チェックリストと直し方

書き換える前に、原文を次のチェックリストで診断します。当てはまる項目を潰していくのが基本作業です。詳細な対処例は `references/ai-japanese-antipatterns.md` を参照。

1. **冗長な接続詞・つなぎ言葉が多い**
   「また」「そして」「さらに」「したがって」「その一方で」を毎文の頭に置きがち。
   → 半分以上は削る。文と文は接続詞なしでも意味がつながることが多い。残すなら位置と種類に変化をつける。

2. **「〜することができます」の過剰使用**
   可能表現をすべて「〜することができます」で表現してしまう。
   → 「〜できます」に短縮。文脈で不要なら可能表現ごと落とす（例：「利用することが可能です」→「使えます」）。

3. **同語反復・同じ語尾の連続**
   「〜です。〜です。〜です。」と語尾が続く／同じ名詞や副詞（「非常に」「しっかりと」「様々な」）を多用。
   → 語尾に体言止め・問いかけ・「〜ます」を混ぜる。同義語や指示語で言い換える。強調副詞は削るか具体表現に置換。

4. **翻訳調・直訳調**
   「〜における」「〜に関して」「〜という点において」「私たちは〜を提供します」「あなたは〜できます」など、英語の構文をなぞった言い回し。無生物主語（「この機能はあなたに〜を提供します」）。
   → 日本語の自然な語順・視点に組み替える。主語を省く、動作主を人に戻す、「〜が」で始める。「あなた」「私たち」は多くの場合省略できる。

5. **抽象的で中身のない一般論**
   「〜は重要です」「近年注目されています」「様々な場面で活用できます」など、具体を欠いた総論だけで進む。
   → 具体例・数字・固有名詞・体験を足す（事実として確認できる範囲で）。読者が絵を描ける表現にする。

6. **箇条書き過多・見出し過多**
   何でも箇条書きにして、地の文（つながった文章）が痩せる。
   → 流れで読ませるべき箇所は文章に戻す。箇条書きは「並列の項目」に限定する。

7. **1文が長い／修飾の入れ子が深い**
   1文に情報を詰め込み、読点でつなぎ続ける。
   → 40〜60字程度を目安に切る。一文一義。修飾語は被修飾語の近くに置く。

8. **過剰な丁寧・過剰なクッション**
   「〜かと思います」「〜させていただきます」「〜のほう」を多用し、断定を避けすぎる。
   → 言い切れるところは言い切る。敬語は正しく、しかし重ねすぎない。

9. **決まり文句の総まとめ**
   「いかがでしたか？」「ぜひ参考にしてみてください」「本記事では〜について解説しました」などのテンプレ締め。
   → 具体的な次の一歩や、書き手の視点で締める。

## リライト手順

次の順序で進めます。順序を守ると、意図を壊さずに自然さを上げられます。

1. **原文の意図を保持する（理解フェーズ）**
   何を伝えたい文章か、対象読者は誰か、事実として動かせない情報（数字・固有名詞・主張）は何かを先に把握する。ここを飛ばすと「自然だが内容がずれた文」ができる。

2. **トーンを設定する（トンマナ決め）**
   敬体（です・ます）／常体（だ・である）のどちらか、フォーマル度、一人称・二人称、絵文字や記号の可否、想定読者との距離感を決める。指定がなければ用途別の指針（下記）を既定にする。Reference Folder があればそれを最優先で踏襲する。

3. **表記を統一する（表記ゆれ・送り仮名）**
   同義語・送り仮名・漢字/かな/カタカナの開き方・数字と単位・記号をそろえる。「申し込み／申込み」「行う／おこなう」「出来る→できる」など。判断基準は `references/tone-guide.md`。迷ったら一文書内で一貫させることを最優先。

4. **リズムを調整する（ゆらぎ）**
   語尾・文長・接続を単調にしない。長短の文を交互に置く。体言止め・問いかけ・言い切りを混ぜる。声に出して読み、つまる所・息切れする所を直す。

5. **最終チェック（校正）**
   - 意図・事実は原文どおりか（勝手に足していないか）
   - 症状チェックリスト9項目が残っていないか
   - トーンが最初から最後までブレていないか
   - 表記ゆれがないか
   - 声に出して自然に読めるか
   ビフォーアフターで見せる場合は、何をなぜ直したかを一言添える。

## Reference Folder の使い方

「Reference Folder」は、踏襲したいお手本の文体サンプルやモデルデータを置く場所です。運用の流れ：

1. ユーザーが用意した過去記事・SNS投稿・メルマガ・スタイルガイドなどを、参照用フォルダ（例：`reference/` や添付ファイル）として読み込む。
2. サンプルから**文体の特徴を抽出**する：敬体/常体、一人称（私／僕／弊社／当社）、語尾のクセ、一文の長さ、漢字とかなの比率、絵文字・記号の使い方、頻出フレーズ、避けている表現、句読点の打ち方。
3. 抽出した特徴を**チェックリスト化**し、新しい文章がそれに沿っているか照合しながら書く／直す。
4. サンプルにない語彙やトーンを勝手に持ち込まない。迷ったらサンプルの実例に合わせる。

サンプルが複数トーンを含む場合は、用途（SNS/ブログ/メルマガ）ごとに分けて特徴を取ると精度が上がります。サンプルが少ないときは、共通する語尾と一人称だけでも先に固定すると効果が大きい。

## 用途別のトーン指針

出力先によって自然な距離感が変わります。既定値として使い、Reference Folder があれば上書きします。

- **SNS投稿（X / Instagram など）**
  距離が近い。常体または軽い敬体、一文を短く、体言止めや問いかけで勢いを出す。冒頭で引きを作る。ハッシュタグ・改行で余白を作る。かしこまりすぎない。1投稿1メッセージ。

- **ブログ記事**
  読み物。敬体が基本。導入で読者の課題に触れ、地の文でしっかり説明する。見出しで構造を見せつつ、箇条書きは並列項目に限定。体験・具体例を入れて一次情報感を出す。テンプレ的な締め（「いかがでしたか」）は避ける。

- **メールマガジン**
  1対1で語りかける手紙のトーン。敬体、一人称と二人称の距離を一定に保つ。冒頭の挨拶〜本題〜行動喚起（CTA）の流れ。1通1テーマ。件名と書き出しで開封後の続きを読ませる。売り込みすぎず、読者の利益を主語にする。

用途別の詳細な指針とトンマナ設定項目は `references/tone-guide.md` を参照。

## ビフォーアフターの実例

より多くの実例は `examples/before-after.md` にあります。ここでは代表例を示します。

**例1：翻訳調・冗長（→ SNS/汎用）**

- Before：「本製品を利用することによって、あなたは業務の効率化を実現することができます。また、様々な機能を活用することが可能となっております。」
- After：「この製品を使えば、業務がぐっと効率化します。機能もひと通りそろっています。」
- 直した点：無生物主語＋「あなた」を削除／「〜することができます」→「〜します」／「また」削除／「様々な」「〜が可能となっております」を具体・簡潔に。

**例2：同語反復・単調（→ ブログ）**

- Before：「このツールは便利です。操作も簡単です。導入も簡単です。初心者にもおすすめです。」
- After：「このツールは、とにかく操作がわかりやすい。導入もつまずきません。初めての人こそ試してほしい一本です。」
- 直した点：「〜です」の連続を解消／「簡単」の反復を言い換え／語尾に言い切りと体言止めを混ぜてリズムを作る。

**例3：過剰な丁寧・テンプレ締め（→ メルマガ）**

- Before：「本日はお時間をいただきありがとうございます。今回ご紹介させていただく内容について、ぜひ参考にしていただければと思います。いかがでしたでしょうか。」
- After：「今日はひとつだけ、お伝えしたいことがあります。読み終わったころには、次の一歩が見えているはずです。」
- 直した点：クッション言葉と「させていただく」の重複を削減／テンプレ導入・締めを、読者の利益を主語にした具体的な語りかけに。
