# 表記ゆれ統一リスト

文書内で揺れやすい語の実用リスト。リライト手順3（表記統一）の照合用に使う。

**推奨欄の根拠マーク**：
- ◎ … 公的・業界標準に明確な根拠がある（JTF日本語標準スタイルガイド／内閣告示／「公用文作成の考え方」）
- ○ … 一般的な慣行（Web・出版で主流。規定というより読みやすさの定石）
- △ … どちらも可。媒体・分野に依存するので、**文書内でどちらかに統一**すればよい

大原則：**Reference Folder の実例 ＞ 媒体の慣習 ＞ このリスト ＞ 一文書内で一貫**。リストと違う表記でも、お手本や媒体がそちらならそちらに合わせる。

---

## 1. 漢字の開き（漢字 → ひらがな）

補助動詞・形式名詞・接続詞をひらがなにするのは「公用文作成の考え方」にもある公的基準。本動詞・実質名詞として使う場合は漢字のままでよい（例：資料を頂く＝もらうの謙譲は漢字可、〜していただく＝補助動詞はひらがな）。

| ゆれ | 推奨 | 根拠・備考 |
| --- | --- | --- |
| 頂く／いただく | いただく | ◎ 補助動詞（〜していただく）。本動詞「お菓子を頂く」は漢字可 |
| 下さい／ください | ください | ◎ 補助動詞（〜してください）。本動詞「水を下さい」（=くれ）は漢字可 |
| 致します／いたします | いたします | ◎ 補助動詞（お願いいたします）。本動詞「不徳の致すところ」は漢字 |
| 出来る／できる | できる | ◎ 公用文でひらがな |
| 頂戴／ちょうだい | ちょうだい | ○ 話し言葉調の文脈ではひらがなが自然 |
| 貰う／もらう | もらう | ○ 特に補助動詞「〜してもらう」 |
| 欲しい／ほしい | ほしい | ○ 補助形容詞「〜してほしい」。実質「水が欲しい」は漢字可 |
| 無い／ない | ない | ○ 補助形容詞「問題ない」「読めなくない」 |
| 見て頂く・見て行く／見ていただく・見ていく | ひらがな | ◎ 「〜ていく」「〜てくる」「〜てみる」「〜ておく」等の補助動詞 |
| 事／こと | こと | ◎ 形式名詞（大事なこと）。実質名詞「事を構える」は漢字 |
| 物／もの | もの | ◎ 形式名詞（〜するもの）。実物を指すなら漢字可 |
| 時／とき | とき | ◎ 形式名詞（困ったとき）。時刻・時代を指すなら漢字 |
| 所／ところ | ところ | ◎ 形式名詞（今のところ）。場所そのものは漢字可 |
| 為／ため | ため | ◎ |
| 通り／とおり | とおり | ◎ 「次のとおり」。道路・「〇〇通り」は漢字 |
| 訳／わけ | わけ | ○ 形式名詞（〜するわけではない）。「訳す」の意味は漢字 |
| 筈／はず | はず | ○ |
| 等／など | など | ○ 一般向け文章は「など」。公用文・法令では「等」も正式（読みは「とう」） |
| 位／くらい・ぐらい | くらい | ○ 程度の意。地位・位置の意味は漢字 |
| 程／ほど | ほど | ○ 程度の意（3日ほど） |
| 迄／まで | まで | ◎ 助詞はひらがな |
| 又／また | また | ◎ 接続詞はひらがな（公用文の原則） |
| 但し／ただし | ただし | ◎ 接続詞 |
| 尚／なお | なお | ◎ 接続詞 |
| 従って／したがって | したがって | ◎ 接続詞。動詞「指示に従って」は漢字 |
| 更に／さらに | さらに | ◎/△ 接続詞はひらがな（公用文）。副詞は公用文だと「更に」だが、Web・SNSではひらがなが主流 |
| 及び・並びに・又は・若しくは／および・ならびに・または・もしくは | 媒体次第 | △ 公用文・法令は漢字が正式。一般向けはひらがなが読みやすい。文書内で統一 |
| 是非／ぜひ | ぜひ | ○ 副詞はひらがな。名詞「是非を問う」は漢字 |
| 様々／さまざま | さまざま | ○ そもそも多用しない（症状5）。「様」を使うのは敬称・様子の意のとき |
| 色々／いろいろ | いろいろ | ○ |
| 沢山／たくさん | たくさん | ○ |
| 丁度／ちょうど | ちょうど | ○ |
| 一旦／いったん | いったん | ○ |
| 予め／あらかじめ | あらかじめ | ○ |
| 殆ど／ほとんど | ほとんど | ○ |
| 概ね／おおむね | おおむね | ○ |
| 全て／すべて | すべて | △ 「全て」は常用漢字表内で公用文は漢字も可。Web文章はひらがなが主流。統一すればどちらでも |
| 分かる／わかる | 媒体次第 | △ 公用文・新聞は「分かる」。やわらかい文章は「わかる」。統一が最優先 |
| 良い／よい・いい | よい | △ 敬体の地の文は「よい」が無難。「いい」は話し言葉調。漢字「良い」は品質評価の文脈で可 |
| 頃／ころ・ごろ | ころ・ごろ | ○ 「3時ごろ」「子どものころ」 |
| 御／ご・お | ご・お | ○ 一般向けは「ご案内」「お知らせ」。公用文の告示類では「御」も使われる |
| 有難う／ありがとう | ありがとう | ○ |
| 宜しく／よろしく | よろしく | ○ |
| 一番／いちばん | 媒体次第 | △ 順位は「1番」、程度の副詞はどちらも流通。文書内で統一 |

## 2. 送り仮名

原則は内閣告示「送り仮名の付け方」の本則＝**動詞は送り仮名を省かない**（JTFも同告示に準拠）。名詞化・複合語では省いた形が慣用として固定しているものがある（申込書・受付・売上高など）。動詞形と名詞形で表記が変わるのは誤りではないが、同じ用法内では統一する。

| ゆれ | 推奨 | 根拠・備考 |
| --- | --- | --- |
| 行う／行なう | 行う | ◎ 本則。「行なう」は許容（「行った」の読み分け目的） |
| 表す／表わす | 表す | ◎ 本則 |
| 現れる／現われる | 現れる | ◎ 本則 |
| 申し込み／申込み／申込 | 申し込み | ◎ 動詞「申し込む」は必ず送る。複合語「申込書」「申込期限」は慣用で送らない |
| 問い合わせ／問合せ／問合わせ | 問い合わせ | ○ 「お問い合わせフォーム」。ボタンラベル等の短縮で「問合せ」も流通 |
| 取り扱い／取扱い／取扱 | 取り扱い | ○ 複合語「取扱説明書」は送らないのが慣用 |
| 打ち合わせ／打合せ／打ち合せ | 打ち合わせ | ○ |
| 引っ越し／引越し／引越 | 引っ越し | ○ 社名・サービス名（「引越センター」等）は固有名詞に従う |
| 売り上げ／売上げ／売上 | 用法で使い分け | △ 動詞由来の一般文は「売り上げ」、会計用語は「売上」「売上高」で固定 |
| 受け付け／受付け／受付 | 用法で使い分け | ○ 動作は「受け付ける・受け付け」、場所・係は「受付」 |
| 締め切り／締切り／締切 | 締め切り | ○ 「締切日」など複合語は送らない形が慣用 |
| 振り込み／振込み／振込 | 用法で使い分け | ○ 動作は「振り込む」、用語は「振込手数料」「銀行振込」 |
| 立ち上げ／立上げ | 立ち上げ | ○ |

## 3. カタカナ語

JTF日本語標準スタイルガイドは**語末の長音を原則省略しない**（2.1.6）。かつての工学系・JIS慣行（3音以上は長音省略：サーバ、ユーザ）は現在少数派で、一般向けは長音ありが主流。どちらを選んでも**文書内で必ず統一**。

| ゆれ | 推奨 | 根拠・備考 |
| --- | --- | --- |
| サーバ／サーバー | サーバー | ◎ JTF 2.1.6。技術文書の旧慣行では「サーバ」も残る |
| ユーザ／ユーザー | ユーザー | ◎ 同上 |
| コンピュータ／コンピューター | コンピューター | ◎/△ JTF・新聞放送は長音あり。IT業界文書では省略形も現役 |
| プリンタ／プリンター | プリンター | ◎/△ 同上 |
| フォルダ／フォルダー | どちらも可 | △ Microsoftは「フォルダー」、Web一般は「フォルダ」も多い。統一が最優先 |
| ブラウザ／ブラウザー | どちらも可 | △ 同上（Google系は「ブラウザ」、MS系は「ブラウザー」） |
| インターフェース／インターフェイス／インタフェース | どれか1つに | △ 3形とも流通。JIS系は「インタフェース」。文書内統一 |
| ウイルス／ウィルス | ウイルス | ○ 新聞・医療系の標準表記 |
| ソフトウェア／ソフトウエア | ソフトウェア | △ IT業界は「ウェア」、新聞は「ウエア」 |
| スマートフォン／スマホ | 初出で決める | △ かたい媒体は「スマートフォン（以下スマホ）」、カジュアルは最初から「スマホ」 |
| メール／Eメール／eメール | メール | ○ 文脈で電子メールと分かるなら「メール」で十分 |
| バイオリン／ヴァイオリン | バイオリン | ○ 内閣告示「外来語の表記」第1表の範囲（ヴを使わない）が一般的。固有名詞は原表記に従う |
| ウェブ／Web／WEB | どれか1つに | △ 「WEB」の全大文字は避けるのが慣行（Webは固有名詞由来） |

## 4. 数字・単位

| ゆれ | 推奨 | 根拠・備考 |
| --- | --- | --- |
| 全角数字／半角数字 | 半角 | ◎ JTF 2.1.8。横書きの算用数字は半角に統一 |
| 1000／1,000 | 1,000 | ◎ JTF 2.1.10。4桁以上は3桁区切りのカンマ。桁区切りしない流儀なら文書内で一貫 |
| 一つ／1つ／ひとつ | 用法で決める | △ 数として数えるなら「1つ」、慣用・強調なら「一つ／ひとつ」。基準を決めて統一 |
| 一石二鳥・第一印象 | 漢数字のまま | ○ 熟語・慣用句・成語の数字は算用数字にしない |
| 数十人・十数件 | 漢数字 | ○ 概数は漢数字が読みやすい |
| ％／%／パーセント | 半角% | △ 和文中に「パーセント」と書く流儀も可。混在させない |
| 10時30分／10:30 | 媒体次第 | △ 地の文は「10時30分」、表・箇条書きは「10:30」のような使い分けも可。ルールを決める |
| 5キロ／5km／5㎞ | 5km | ○ 単位は半角英字。組文字（㎞・㌔）は使わない |

## 5. 記号・約物

| ゆれ | 推奨 | 根拠・備考 |
| --- | --- | --- |
| ！!／？? | 全角「！」「？」 | ◎ JTF 4.2.1／4.2.2。和文中は全角、そもそも多用しない。文中で後ろに文が続くときは直後に全角スペース |
| 中黒（・） | 全角 | ◎ JTF 4.2.4。並列の区切り・カタカナ複合語の区切りに |
| …／‥／...（ピリオド3つ） | 三点リーダー「…」 | ○ ピリオドの代用はしない。出版慣行は「……」と2倍、Webでは「…」1つも定着（△）。文書内で統一 |
| ダッシュ（—／―／-） | 全角ダッシュ | △ 「——」と2倍にする出版慣行と1つの流儀がある。ハイフン「-」で代用しない |
| 〜（波ダッシュ）／~（チルダ） | 全角「〜」 | ○ 範囲（10〜20分）は全角波ダッシュ。半角チルダは使わない |
| 、。／，． | 「、」「。」 | ◎ 「公用文作成の考え方」で横書きも読点は「、」が原則に。学術・理系の一部に「，．」の流儀が残る（媒体に従う） |
| 「」『』（）［］ | 用途を決めて統一 | ○ 会話・引用は「」、作品名・「」内の引用は『』、補足は（）。全角括弧が基本、半角()は英数字のみの補足に許容（△） |
| 全角英数／半角英数 | 半角 | ◎ 英字・数字は半角に統一（JTF） |
| 半角カナ | 使わない | ◎ 一般的な禁止事項。カタカナは全角 |
| 英数字と和文の間のスペース | 入れない | ◎/△ JTF 3.1.1は「スペースなし」が標準。入れる流儀（主にIT系ドキュメント）も広く存在するため、どちらかに統一 |

## 使い方

1. リライト手順3（表記統一）で、原文に出てくる語をこのリストと照合する。
2. △の項目は「どちらにするか」をその場で決め、トンマナ設定シート（`tone-guide.md`）にメモして以後固定する。
3. Reference Folder があるときは、サンプル内の実際の表記がこのリストより優先。
4. 検索置換で機械的に直すときは、本動詞／補助動詞の区別（頂く・下さい・致す）だけは目視で確認する。一括置換すると「水を下さい」まで壊れる。
